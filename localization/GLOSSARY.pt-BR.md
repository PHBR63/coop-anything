# Terminologia da tradução

| Termo original | Uso em pt-BR |
|---|---|
| co-op | modo cooperativo; cooperativo quando adjetivo |
| single-player | para um jogador |
| engine | motor |
| host | host; máquina que hospeda a sessão |
| client | cliente |
| host-authoritative | com autoridade do host |
| relay | retransmissor; retransmissão para o mecanismo |
| port forwarding | redirecionamento de portas |
| sync / desync | sincronização / dessincronização |
| write-up | relato técnico |
| playbook | guia; roteiro quando se tratar de sequência de ações |
| build | compilação; versão compilada quando se tratar do artefato |
| ship | distribuir |
| runtime | tempo de execução |
| fixture | dados de teste; manter o identificador técnico quando necessário |
| flight recorder | gravador de eventos |
| mutation twin | variante de mutação |
| ownership | responsabilidade; manter nomes de módulos e identificadores |
| epoch | época |
| handoff | transferência de responsabilidade |
| warm pool | conjunto de instâncias já inicializadas |
| hook | hook |
| fuzzer / fuzzing | fuzzer / fuzzing |
| lockstep | lockstep |
| skill | skill, para manter correspondência com o recurso dos agentes |

Nomes de jogos, produtos, pacotes e bibliotecas permanecem no original. Termos de interface como `Play`, `Library`, `On this PC` e `Try it` são mantidos e explicados em português quando necessário. Os valores estruturais `unknown`, `none`, `automated` e demais enumerações permanecem em inglês para preservar a compatibilidade.

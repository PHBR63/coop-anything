# <a id="resident-evil-2-2019-remake-online-campaign-co-op-research"></a>Resident Evil 2 (remake de 2019): pesquisa sobre campanha cooperativa on-line

## <a id="scope-and-research-date"></a>Escopo e data da pesquisa

Esta entrada trata de campanha cooperativa on-line entre PCs separados, não de partidas locais com tela compartilhada ou dividida. A data da pesquisa é **2026-10-23**; esta revisão editorial não representa uma nova busca nem altera a data de verificação do diretório.

Nenhum projeto lançado de campanha cooperativa on-line foi registrado nas fontes pesquisadas naquela data. Esse é o resultado de uma busca limitada e datada, não uma afirmação de que não exista algum protótipo privado ou ainda não lançado.

## <a id="existing-local-projects"></a>Projetos locais existentes

- [Local Couch Co-op / HUNK's Friend](https://www.nexusmods.com/residentevil22019/mods/2938): modo cooperativo local com REFramework. Possui uma entrada própria no diretório.
- [RE2 Party Mode](https://www.nexusmods.com/residentevil22019/mods/3024): projeto local de tela dividida, também listado separadamente.

Multiplayer local não comprova sincronização de campanha on-line. Esses projetos são descobertas relevantes, mas não versões on-line que preencham a lacuna.

## <a id="search-coverage-and-limitations"></a>Cobertura e limitações da busca

A pesquisa registrada abrangeu busca de repositórios no GitHub, as páginas e publicações do Nexus Mods acima, ModDB e busca geral na web. Não foram preservados registros detalhados das consultas. Fóruns Steam e Reddit não foram verificados novamente de forma independente para esta entrada. A lista `searched` do diretório registra explicitamente essa cobertura e suas limitações.

## <a id="evidence-boundary"></a>Limite das evidências

Esta PR contém apenas pesquisa: **não fornece testes do jogo nem um mod on-line jogável**. Simulações de protocolo, contagens de sessões de fuzzing e testes de recursos isolados não comprovam objetos sincronizados, progressão da história ou campanha jogável. Não são usados como evidência para esta entrada de lacuna. Seu nível de QA permanece `none`.
